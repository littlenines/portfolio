# Portfolio

A cyberpunk city-pop portfolio built with Astro, SCSS (7-1) and GSAP. Mobile first, with three themes
(surface, netspace and a hidden evangelion theme) and a seeded skyline rendered at build time.

## Commands

| Command         | Action                                                       |
| :-------------- | :----------------------------------------------------------- |
| `pnpm install`  | Install dependencies                                         |
| `pnpm dev`      | Dev server at `localhost:4321`                               |
| `pnpm check`    | Type-check `.astro` and `.ts` files                          |
| `pnpm format`   | Fix formatting and lint issues (Prettier, ESLint, Stylelint) |
| `pnpm lint`     | Check formatting and lint rules without changing files       |
| `pnpm test`     | Unit tests (Vitest)                                          |
| `pnpm test:e2e` | Build, then browser and accessibility tests (Playwright)     |
| `pnpm build`    | Type-check, then build to `./dist/`                          |
| `pnpm preview`  | Preview the production build                                 |
