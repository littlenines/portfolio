# Docs

How the portfolio is put together, and where to change things.

| Doc                             | Read it when you want to…                                                                             |
| :------------------------------ | :---------------------------------------------------------------------------------------------------- |
| [Conventions](conventions.md)   | Write code that matches the rest: naming, constants, styles, tests, commits                           |
| [Content](content.md)           | Change text, projects, the stack list, links or the email                                             |
| [Architecture](architecture.md) | Understand the folders, how components, data and scripts fit together, and what happens at build time |
| [Styles](styles.md)             | Find or change a style, add a component, use breakpoints and mixins                                   |
| [Theming](theming.md)           | Change theme colours, add a themed style, understand the theme switch and the easter egg              |
| [Scripts](scripts.md)           | Change motion, the loader or any interactive effect                                                   |

Quick start: `pnpm install`, then `pnpm dev` and open http://localhost:4321.
